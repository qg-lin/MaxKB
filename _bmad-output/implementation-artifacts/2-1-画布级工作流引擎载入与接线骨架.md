Status: done

## Story

As a 编排工程师,
I want 打开编排工作区能看到一块图形画布，可在其上放置节点并通过边缘连线搭建逻辑骨架,
so that 直观地规划整个机器人的意图走向而无需书写 Python 解析代码.

## Acceptance Criteria

1. **Given** 我处于应用的"高级编排"界面
   **When** 页面加载时
   **Then** 系统应利用 LogicFlow 绘制出网格化的拖拽面板供我操作
   **And** Vue 组件销毁时 (onUnmounted) 必须彻底释放 LogicFlow 画布对象防止内存泄漏

### 📐 LogicFlow 初始化模式（现有实现速查）

**主画布组件**（`ui/src/workflow/index.vue`）核心结构：

```vue
<template>
  <div className="workflow-app" id="container"></div>
  <Control class="workflow-control" v-if="lf" :lf="lf"></Control>
  <TeleportContainer :flow-id="flowId" />
</template>

<script setup lang="ts">
import LogicFlow from '@logicflow/core'
import { ref, onMounted, onUnmounted, inject } from 'vue'

const lf = ref()

onMounted(() => {
  renderGraphData()
})

onUnmounted(() => {
  disconnectAll()  // ← AC2 内存清理：断开所有 Teleport 连接
})

const renderGraphData = (data?: any) => {
  const container: any = document.querySelector('#container')
  lf.value = new LogicFlow({
    plugins: [Dagre, SelectionSelect],
    textEdit: false,
    adjustEdge: false,
    adjustEdgeStartAndEnd: false,
    background: { backgroundColor: '#f5f6f7' },
    grid: {
      size: 10,
      type: 'dot',              // ← AC1 网格化拖拽面板
      config: { color: '#DEE0E3', thickness: 1 },
    },
    keyboard: { enabled: true },
    isSilentMode: false,
    container: container,
  })

  // 批量注册所有节点类型（动态 import glob）
  lf.value.batchRegister([
    ...Object.keys(nodes).map((key) => nodes[key].default),
    AppEdge,
    loopEdge,
  ])

  lf.value.setDefaultEdgeType('app-edge')
  lf.value.render(data ? data : {})

  // 图渲染完成后自动 fit 或居中
  setTimeout(() => {
    if (lf.value.graphModel?.nodes.length > 1) {
      lf.value?.fitView()
    } else {
      lf.value?.translateCenter()
    }
  }, 500)
}

// 对外暴露接口供父组件调用
defineExpose({
  onmousedown,   // 拖拽添加节点（DnD）
  validate,      // 画布全节点校验
  getGraphData,  // 序列化图数据（保存前调用）
  addNode,       // 点击添加节点（居中添加）
  clearGraphData,
  renderGraphData,
  render,
})
</script>
```

### ⚡ 关键架构约束（开发防灾护栏）

**1. LogicFlow 内存管理（AC2 核心）**：
```typescript
// ✅ 正确：workflow/index.vue 已实现

  disconnectAll()  // 清除所有 Teleport 连接（防止节点编辑面板内存泄漏）
})
// ❌ 禁止：不能仅做 lf.value = null 而不清理 Teleport
```

**2. 节点动态注册（禁止硬编码）**：
```typescript
// ✅ 正确：通过 import.meta.glob 动态加载所有节点
const nodes: any = import.meta.glob('./nodes/**/index.ts', { eager: true })
lf.value.batchRegister([...Object.keys(nodes).map((key) => nodes[key].default)])

// ❌ 禁止：逐个手动 import 和 register
```

**3. 保存前必须校验**：
```typescript
// ✅ 正确：先 validate() 再 getGraphData()
await workflowRef.value.validate()        // 所有节点通过校验
const graphData = workflowRef.value.getGraphData()
await putApplication(id, { work_flow: graphData })

// ❌ 禁止：跳过 validate 直接保存
```

**4. 长事务走 Celery**：
- 工作流执行（运行推理）是长事务，后端通过 Celery 处理，禁止在 Django View 内直接调用阻塞

**5. 工作流模式通过 inject 传递**：
