# Story 8.1: 参数提取节点前端 - 新增自定义提示词配置界面

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a 编排工程师,
I want 在配置"参数提取"节点时，能看到一个提示词编辑区域，可以选择使用系统默认提示词或切换为自定义提示词并编辑其内容,
so that 能根据具体业务场景调整参数提取的指令逻辑，而不必受限于系统内置的固定模板.

## Acceptance Criteria

1. **Given** 我在工作流编排画布中，打开了"参数提取"节点的配置面板
   **When** 我查看节点设置区域
   **Then** 应在"提取参数"表格下方显示"提示词"配置区域，包含"系统默认"和"自定义"两个选项（默认选中"系统默认"）

2. **And** 选择"系统默认"时，以只读/折叠方式展示当前系统默认提示词内容供参考

3. **And** 选择"自定义"时，显示一个可编辑的文本域（textarea），预填系统默认提示词内容，用户可自由修改

4. **And** 自定义提示词文本域中应以 placeholder 或提示方式告知用户可用的模板变量：`{{question}}`（输入文本）和 `{{properties}}`（提取配置）

5. **And** 保存后，节点数据 `node_data` 中应包含 `prompt_type`（`'system'` 或 `'custom'`）和 `custom_prompt`（自定义提示词文本）字段

6. **And** 编辑已有节点时，能正确还原之前保存的提示词类型和内容

### 系统默认提示词内容（前端常量定义）

后端 `prompt` 常量（[base_parameter_extraction_node.py:21-37](apps/application/flow/step_node/parameter_extraction_node/impl/base_parameter_extraction_node.py#L21)）内容如下。前端需定义相同内容的常量供参考展示和自定义模式预填使用：

```typescript
const DEFAULT_SYSTEM_PROMPT = `Please strictly process the text according to the following requirements:
**Task**:
Extract specified field information from given text

**Enter text**:
{{question}}

**Extract configuration**:
{{properties}}

**Rule**:
- Strictly follow the data and field of Extract configuration
- If not found, use null value
- Only return pure JSON without additional text
- Keep the string format neat`
```

> ⚠️ 注意：`{{question}}` 和 `{{properties}}` 是 Jinja2 模板变量，保持原样（双花括号），不能被 Vue 模板引擎解析。在 Vue 的 `<script setup>` 中以 TypeScript 字符串定义，在模板中使用 `:value="DEFAULT_SYSTEM_PROMPT"` 绑定（不会被 Vue 解析花括号）。

### 精确的代码改动说明

#### 1. `form` 对象新增字段

```typescript
const form = {
  input_variable: [],
  model_params_setting: {},
  model_id: '',
  variable_list: [],
  prompt_type: 'system',   // 新增：默认使用系统默认提示词
  custom_prompt: '',        // 新增：自定义提示词文本（空时前端不发送到后端，后端自动回退）
}
```

#### 2. `onMounted` 中兼容旧节点初始化

```typescript
onMounted(() => {
  getSelectModel()
  set(props.nodeModel, 'validate', validate)
  // 兼容旧节点：若 node_data 已存在但无 prompt_type，初始化为 'system'
  if (props.nodeModel.properties.node_data && !props.nodeModel.properties.node_data.prompt_type) {
    set(props.nodeModel.properties.node_data, 'prompt_type', 'system')
  }
})
```

#### 3. 添加 `watch`（在 script setup 中）

```typescript
import { computed, onMounted, ref, inject, watch } from 'vue'  // 新增 watch

// 切换为自定义时，若 custom_prompt 为空则预填系统默认提示词
watch(
  () => form_data.value.prompt_type,
  (newVal) => {
    if (newVal === 'custom' && !form_data.value.custom_prompt) {
      set(props.nodeModel.properties.node_data, 'custom_prompt', DEFAULT_SYSTEM_PROMPT)
    }
  }
)
```

#### 4. 模板新增"提示词"配置区域

在 `variable_list` 的 `el-form-item` 之后添加：

```vue
<!-- 提示词配置区域 -->
<el-form-item>
  <template #label>
    <span>{{ $t('workflow.nodes.parameterExtractionNode.prompt.label') }}</span>
  </template>
  <div class="w-full">
    <el-radio-group v-model="form_data.prompt_type" class="mb-8">
      <el-radio value="system">
        {{ $t('workflow.nodes.parameterExtractionNode.prompt.systemDefault') }}
      </el-radio>
      <el-radio value="custom">
        {{ $t('workflow.nodes.parameterExtractionNode.prompt.custom') }}
      </el-radio>
    </el-radio-group>

    <!-- 系统默认：只读展示 -->
    <el-input
      v-if="form_data.prompt_type !== 'custom'"
      type="textarea"
      :autosize="{ minRows: 4, maxRows: 8 }"
      :model-value="DEFAULT_SYSTEM_PROMPT"
      :readonly="true"
      disabled
    />

    <!-- 自定义：可编辑 -->
    <el-input
      v-else
      type="textarea"
      :autosize="{ minRows: 4, maxRows: 12 }"
      v-model="form_data.custom_prompt"
      :placeholder="$t('workflow.nodes.parameterExtractionNode.prompt.placeholder')"
    />
  </div>
</el-form-item>
```

### 前端技术规范

- Vue3 组合式 API（`<script setup lang="ts">`）
- 使用 `lodash.set` 操作 `nodeModel.properties.node_data`（保持与现有代码一致）
- 使用 Element Plus `el-radio-group` + `el-radio`（使用 `value` 属性，非 `label`，EP v2 写法）
- 使用 Element Plus `el-input type="textarea"` 带 `:autosize`（保持与项目其他 textarea 一致）
- 禁止引入任何新的第三方依赖

### 回归安全性分析
