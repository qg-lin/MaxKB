## Story

As a 编排工程师,
I want 能够把预定义的四类核心节点（模型方切换、外部连接、知识搜索、异常兜底出口）置于画布并配置其内部参数,
so that 我的图解骨架能变成真正带有驱动引擎和接口调用能力的行动流.

## Acceptance Criteria

1. **Given** 我已经在一个节点上配置了'模型调用'或者'外接 API'选项
   **When** 我对这个节点填入参数并将其并入到整体流中执行保存时
   **Then** 前端会将 JSON 定义发给 API 层
   **And** 后端能将其存储在对应的 workflow 规范表里而不断开连接

### 📦 工作流持久化机制（AC 核心）

**存储字段**（`apps/application/models/application.py:78`）：
```python
class Application(models.Model):
    work_flow = models.JSONField(verbose_name="工作流数据", default=dict)
    # ApplicationVersion 模型中也有同名字段（第 155 行）
```

**完整保存链路**：
```
用户点击"保存"
  → validate()         # 前端校验所有节点参数（每个节点的 validate 方法）
  → getGraphData()     # 序列化 LogicFlow 图为 JSON（过滤 loop-body-node）
  → putApplication(application_id, { work_flow: graphData })
  → PUT /workspace/{workspace_id}/application/{application_id}
  → Django View → Serializer
  → Application.work_flow = graphData (JSONField 写入)
  → Application.save()
```

**后端工作流校验**（保存时触发，`apps/application/flow/common.py`）：
```python
def is_valid(self):           # 第 203-205 行
    self.is_valid_start_node()
    self.is_valid_base_node()
    self.is_valid_work_flow()  # 从 start_node 开始递归遍历校验连通性

def is_valid_work_flow(self, up_node=None):  # 第 229-235 行
    if up_node is None:
        up_node = self.get_start_node()
    next_nodes = self.get_next_nodes(up_node)
    for next_node in next_nodes:
        self.is_valid_work_flow(next_node)   # 递归遍历
```

### ⚡ 关键架构约束

**1. 节点参数存储在 `properties` 字段**（JSON 结构）：
```json
{
  "nodes": [{
    "id": "node-uuid",
    "type": "ai-chat-node",
    "x": 200, "y": 300,
    "properties": {
      "model_id": "model-uuid",
      "system_message": "你是一个助手...",
      "temperature": 0.7,
      "stepName": "AI 对话"
    }
  }]
}
```

**2. 前端 Axios 拦截器必须注入 Bearer Token**：
```typescript
// ui/src/api/application/application.ts
// putApplication 通过 Axios 全局拦截器自动携带 Authorization: Bearer {token}
// 禁止在组件内裸写 axios，所有 HTTP 请求走 ui/src/api/ 封装
```

**3. 保存前必须校验所有节点**：
```typescript
// ✅ 正确顺序
await workflowRef.value.validate()      // 校验包括 model_id 必填等规则
const graphData = workflowRef.value.getGraphData()
await putApplication(id, { work_flow: graphData })
```

**4. 知识库节点特殊宽度**：
